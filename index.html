    자료실

    필요한 순간, 다음 세계를 꺼내보세요. 연구하고, 기록하고, 만들고, 함께 즐기는 일곱 가지 공간의 링크를 모았어요.

    링크 관리하기

    자료실 링크 관리

    새 링크를 등록하고, 이름과 공간을 바꾸고, 순서를 정할 수 있어요. 변경 내용은 지금 쓰는 이 브라우저에만 저장돼요.

    링크를 추가·수정·삭제하려면 관리 암호를 입력해 주세요.

    숨긴 기본 링크는 눈 모양 버튼으로 다시 보이게 할 수 있어요.

    사이트 만들기

    ChatGPT에서 만든 홈페이지를 index.html과 vercel.json 형태로 준비해 Vercel에 올리면, 누구나 접속할 수 있는 온라인 사이트가 돼요.

    Vercel 열기

    홈페이지를 인터넷에 공개하는 가장 쉬운 흐름

    1. 홈페이지 만들기
    2. Vercel용 ZIP 만들기
    3. 압축 풀기
    4. Vercel에 프로젝트 업로드
    5. 생성된 주소로 접속하기

    ChatGPT에 이렇게 요청하세요

    홈페이지를 다 만든 뒤 아래 한 문장만 추가로 보내면 Vercel에 올리기 좋은 형태로 정리해 줘요.

    이 홈페이지를 Vercel에 바로 올릴 수 있도록 `index.html` + `vercel.json` 형태로 압축 만들어줘

    수정할 기존 홈페이지가 있다면 HTML 파일을 먼저 첨부하고 이 문장을 함께 보내면 더 정확해요.

    받은 ZIP 확인하기

    ZIP 안의 기본 구조는 두 파일이에요.

    index.htmlvercel.json

    ZIP 파일을 그대로 올리기보다 먼저 압축을 풀고, 두 파일이 들어 있는 폴더를 준비해 주세요.

    Vercel에 실제로 올리는 순서

    Vercel 접속

    Vercel 열기 버튼을 눌러 Vercel에 접속하고 로그인합니다.

    새 프로젝트 만들기

    대시보드에서 새 프로젝트를 만드는 메뉴로 들어갑니다. 로컬 프로젝트를 올릴 수 있는 화면에서 방금 압축을 푼 홈페이지 폴더를 선택합니다.

    파일 구조 확인

    선택한 프로젝트의 최상위 폴더에 index.html과 vercel.json이 들어 있어야 합니다. HTML 안에 이미지가 포함된 방식이라면 별도 이미지 파일 없이도 동작할 수 있습니다.

    배포하기

    특별히 바꿀 설정이 없다면 기본 설정으로 배포를 진행합니다. 배포가 완료되고 상태가 Ready로 표시되면 온라인 공개가 완료된 것입니다.

    생성된 주소 확인

    배포가 끝나면 프로젝트이름.vercel.app 형태의 주소가 생성됩니다. 이 주소를 다른 사람에게 보내면 휴대폰이나 PC에서 사이트에 접속할 수 있습니다.

    기존 사이트를 고치고 싶을 때

    기존 HTML 파일을 ChatGPT에 첨부한 뒤 “이 부분을 수정해줘”라고 요청하고, 마지막에 “수정하고 index.html + vercel.json 형태로 압축 만들어줘”라고 적으면 관리하기 편해요.

    처음부터 사이트를 만들고 싶다면 아래처럼 요청하면 됩니다.
